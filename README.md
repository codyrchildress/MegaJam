# This Is Your Shot (MegaJam)

UEFN project for MegaJam.

## What lives where

| Folder | Contents |
| --- | --- |
| `Docs/` | Design docs, notes, and write-ups to share with the team |
| `Art/` | Source art: images, concepts, PSDs, reference |
| `Content/*.verse` | Verse source (mirrored here for easy reading/review) |

## What this repo is *not*

The UEFN project itself (`.uasset`, `.umap`, `__ExternalActors__`) is versioned
by Unreal Revision Control inside UEFN, not by git. Those files are ignored here
so the two systems never fight. To work on the island, use UEFN's revision control.
